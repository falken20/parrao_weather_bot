Cloud Scheduler reference. This is not a live configuration export.

The original snapshot was captured in 2020. Its schedule and identity below
are historical examples, not a guarantee of current deployment settings.

Example job:
  name: cron_cercedilla_weather
  location: europe-west1
  schedule: 0 */3 * * *
  timeZone: Europe/Madrid
  httpMethod: POST
  uri: https://europe-west1-cercedilla-weather-bot.cloudfunctions.net/cercedilla-weather-bot
  oidcAudience: same as the target function URI
  oidcServiceAccount: cercedilla-weather-bot@appspot.gserviceaccount.com

Read current settings with an explicit project and location:
$ gcloud scheduler jobs describe cron_cercedilla_weather --project=cercedilla-weather-bot --location=europe-west1 --format="yaml(name,state,schedule,timeZone,lastAttemptTime,httpTarget.uri,httpTarget.httpMethod,httpTarget.oidcToken)"

Use an OIDC identity authorized to invoke the target function. Refer to the
actual daily job configuration separately; its schedule is not recorded here.
