Cloud Functions reference. This is not a live configuration export.

Deployment settings are defined in cloudbuild.yaml. The previous snapshot
contained execution metadata from 2020 and must not be used as current state.

Function entry points:
  cercedilla-weather-bot: parrao_weather_bot
  cercedilla-weather-daily-bot: parrao_weather_bot_daily

Read current metadata without displaying environment-variable values:
$ gcloud functions describe cercedilla-weather-bot --project=cercedilla-weather-bot --region=europe-west1 --format="yaml(name,status,runtime,entryPoint,timeout,serviceAccountEmail,httpsTrigger.url,ingressSettings)"
$ gcloud functions describe cercedilla-weather-daily-bot --project=cercedilla-weather-bot --region=europe-west1 --format="yaml(name,status,runtime,entryPoint,timeout,serviceAccountEmail,httpsTrigger.url,ingressSettings)"

Runtime variable names:
  ENV_PRO, LOG_LEVEL, API_KEY, STATION_ID, DATABASE_URL,
  TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID
  ID_LOG is optional.

Keep credentials and signed source-upload URLs out of configuration examples.
Ingress ALLOW_ALL alone does not establish whether invocation is public;
check effective IAM separately.
